## PAGE 2: ABSTRACT OF THE PROJECT

Traditional tribal handicrafts reflect rich cultural heritage but often lack proper market reach. The FSAD-PS02 project aims to develop a full-stack web platform that enables tribal artisans to showcase and sell their handcrafted products directly to customers without intermediaries.

The platform provides separate roles for Admin, Artisan, Customer, and Cultural Consultant. Artisans can manage product listings and orders, customers can explore products and place orders, admins monitor platform activities, and cultural consultants ensure authenticity of traditional content.

The application is developed using React for the frontend and Spring Boot for the backend, following RESTful architecture and secure role-based access. This project supports digital empowerment of tribal communities while demonstrating practical implementation of Full Stack Application Development concepts.

## PAGE 3: SYSTEM MODULES & FUNCTIONALITY OVERVIEW

### 1. Admin Module

- Manage users and artisans
- Monitor transactions and orders
- Approve or reject product listings
- Resolve customer complaints
- Manage platform content and promotions

### 2. Artisan Module

- Register and log in securely
- Create, update, and delete product listings
- Upload product images and descriptions
- Track orders and sales
- Communicate with customers

### 3. Customer Module

- Browse and search handicraft products
- View product details and artisan profiles
- Place orders and make payments
- Provide reviews and ratings
- Participate in offers and promotions

### 4. Cultural Consultant Module

- Verify authenticity of product descriptions
- Ensure cultural accuracy
- Approve heritage-sensitive content

### Security & Architecture

- Role-based authentication and authorization
- REST API-based communication
- MVC and layered architecture
- Exception handling and logging

## PAGE 5: 2-MONTH PROJECT WORK FRAMEWORK (WEEK-WISE PLAN)

- **Total Duration:** 2 Months (8 Weeks)

- Understand problem statement and project objectives

- Set up GitHub repository and basic project structure

- Design database schema (Users, Products, Orders, Reviews)
- Create Spring Boot project
- Configure database (MySQL/PostgreSQL)
- Implement basic entities and JPA mappings

- Test APIs using Postman

### Week 4: Security & Exception Handling

- Logging using SLF4J & Logback

### Week 6: Frontend-Backend Integration

- Handle client-side validations

### Week 7: Testing & Enhancements

- Perform end-to-end testing
- Fix bugs and improve UI
- Optimize backend APIs
- Add additional features like search and pagination

### Week 8: Deployment & Documentation
